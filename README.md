# Aziz Tunc — Portfolio

Lightweight personal portfolio built with Vite, vanilla HTML/CSS/JS. Header and hero animation are modeled after [jake.ly](https://jake.ly).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Features

- Responsive layout with jake.ly design tokens (`#17191c` background, Geist typography)
- Fixed header with logo hover reveal, nav, and glass CTA button
- EN/DE language toggle on the header CTA
- Figma-style animated hero headline
- Placeholder sections for work, skills, and about
